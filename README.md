# NPTEL C Programming Certification

This repository contains my certificate from the NPTEL C Programming course.

## About the Course
This was a short 3-month certification course focused on the fundamentals of C programming.  
Since I started with little prior experience in C, the course involved learning core concepts within a limited time frame while balancing academic work.

## Topics Covered
- Variables and Data Types
- Operators and Expressions
- Conditional Statements
- Loops
- Functions
- Arrays and Strings
- Pointers
- Basic File Handling

## Learning Outcome
Although the course was fast-paced, it helped me build a strong understanding of the basics of C programming and problem-solving concepts.

## Purpose
This repository is maintained as a record of my progress and foundational learning in C programming.
